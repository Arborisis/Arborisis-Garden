# Implementation Plan: Multi-Hardware ML Intelligence & UI Expansion

**Branch**: `001-multi-hardware-ml-ui` | **Date**: 2026-05-30 | **Spec**: [spec.md](spec.md)

**Input**: [specs/001-multi-hardware-ml-ui/spec.md](spec.md)

## Summary

Adds a 4-signal ML health prediction pipeline (gradient-descent online learning, MLModelVersion rollback), photo storage + LLM visual analysis, weather integration, AI insights caching, Web Push notifications, care calendar, and per-plant moisture calibration — all surfaced via new PWA panels in the garden app. Firmware 0.1.1 fixes TSL2561 lux scaling for 402 ms/1× gain default settings.

## Technical Context

**Language/Version**: TypeScript 5 / Node.js 25 (server), MicroPython 1.23 (firmware)

**Primary Dependencies**: Next.js 16, Prisma 5, Zod 3, `@aws-sdk/client-s3`, `web-push`, `openrouter` (LLM), Open-Meteo (weather, no key)

**Storage**: PostgreSQL (Railway), Railway Object Storage (S3-compatible, plant photos)

**Testing**: Manual + `npm run build` / `npx tsc --noEmit` / `npm run lint` / `npm audit`

**Target Platform**: Railway (Dockerfile multi-stage), PWA (Next.js)

**Project Type**: Web service + PWA + IoT firmware

**Performance Goals**: `POST /api/telemetry` < 200 ms, `GET /api/ml/predict` < 500 ms, full-page PWA shell < 3 s (p95)

**Constraints**: Single Railway Postgres, max 10 DB connections, no Python runtime on server, offline-capable PWA shell

**Scale/Scope**: Single-user household; < 20 plants, < 5 devices

## Phase 0 Research

See [research.md](research.md) for all technology decisions:
- ML weight-learning: gradient descent on 4 bounded weights (rejected: neural net, random forest, Bayesian)
- Weather: Open-Meteo free API (rejected: OpenWeatherMap paid tier)
- Photo storage: Railway Object Storage / S3 (rejected: DB BLOBs per Constitution)
- Web Push: `web-push` + VAPID (rejected: FCM vendor lock-in)
- TSL2561 scaling: normalize raw counts before datasheet formula (rejected: hardcode gain_16x)
- AI insights cache: Memory table, 4h TTL, weather fingerprint key (rejected: Redis)
